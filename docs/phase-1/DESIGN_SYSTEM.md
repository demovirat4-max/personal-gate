# Design System & Visual Specification

## 1. CSS Design Tokens (`src/app/globals.css`)

| Token Name | Color Value | Purpose |
| :--- | :--- | :--- |
| `--bg-page` | `#060913` | Deep navy background surface |
| `--bg-surface` | `#0b1120` | Primary container surface |
| `--bg-surface-elevated` | `#111a2e` | Elevated cards & inputs |
| `--border-subtle` | `rgba(255,255,255,0.08)`| Soft container borders |
| `--accent-cyan` | `#00f0ff` | Primary active accent & countdown |
| `--accent-purple` | `#8b5cf6` | Video player & AI mentor accent |
| `--status-success` | `#10b981` | Completed tasks & system health |

## 2. Visual Principles Applied

* High information density without visual clutter.
* Dark cockpit aesthetic matching the approved visual reference.
* Motion limited strictly to progress bar fills and smooth transitions.

# Phase 8: API Contracts

## Server Actions & Endpoints
- `generateScheduleAction(profileId)`: Generates dynamic macro schedule.
- `replanScheduleAction(scheduleId, options)`: Triggers re-balancing.
- `updateBlockStateAction(blockId, newState)`: Transition block state.
- `getAdherenceReportAction(scheduleId)`: Fetches adherence metrics.

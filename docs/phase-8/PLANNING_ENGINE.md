# Phase 8: Planning Engine

## Deterministic DAG Engine
- **Syllabus Dependency Graph**: Topological sorting of topic prerequisites (e.g., C Programming -> Data Structures -> Algorithms).
- **Capacity Constraint Solver**: Distributes target topic hours based on weekly availability.
- **Buffer Placement Algorithm**: Dynamically inserts contingency blocks after every 3 study blocks to prevent burnout and handle slippage.

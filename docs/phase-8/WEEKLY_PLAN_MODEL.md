# Phase 8: Weekly Plan Model

## Micro-Schedule Structure
The weekly plan allocates daily study blocks across four primary task categories:
- **Concept Study**: Theoretical reading and lecture consumption.
- **Practice Problems**: Standard GATE workbook and exercise solving.
- **PYQ Resolution**: Timed solving of official past year questions.
- **Revision & Flashcards**: Active recall using Phase 6 knowledge items.

> **GATE AIR-1 Command Center** · Generation Auditability & Artifact Storage

## 1. Database Schema Alignment

AI generations are stored in Supabase with complete relational provenance:

```sql
-- AI Requests Audit Log
CREATE TABLE ai_requests (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id TEXT NOT NULL,
    capability TEXT NOT NULL,
    provider TEXT NOT NULL,
    status TEXT NOT NULL,
    input_tokens INT,
    output_tokens INT,
    total_tokens INT,
    estimated_cost_inr NUMERIC(10,4),
    finish_reason TEXT,
    error_code TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- AI Artifacts Provenance Storage
CREATE TABLE ai_artifacts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id TEXT NOT NULL,
    capability TEXT NOT NULL,
    source_type TEXT NOT NULL,
    source_id UUID,
    request_id UUID REFERENCES ai_requests(id),
    title TEXT NOT NULL,
    content_json JSONB NOT NULL,
    saved BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 2. Lineage & Traceability Flow

Every output generated by [`AiOrchestratorService.executeRequest`](file:///c:/Users/yaksh/Downloads/personal%20gate/src/server/services/ai-orchestrator.service.ts#L80-L93) automatically pairs the artifact with:
- `request_id`: Tracing back exact provider, model, execution status, and token costs.
- `source_id`: Linking directly to the lecture ID, mistake ID, or quiz question ID.
- `capability`: Ensuring explicit domain classification.

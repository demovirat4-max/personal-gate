# Phase 9: Historical Evidence Preservation

## Preservation of Legacy Formats & Syllabus Dynamics

GATE exam syllabus and question patterns have evolved significantly between 1991 and 2027.

### Historical Transformations Tracked
- **2021 Syllabus Revision**: Introduction of MSQ (Multiple Select Questions), removal of specific Compiler Design topics (e.g. Code Generation details reduced), and introduction of Data Science & AI paper branch.
- **2014 Online Exam Transition**: Conversion from paper-based OMR to computer-based testing with NAT questions.
- **Legacy Preservation Rule**: Questions prior to 2014 are converted to modern MCQ format while retaining historical evidence flags for retro-analysis.

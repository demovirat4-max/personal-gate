# Phase 9: Phase 5 Adaptive Engine Boundary

## IRT Parameter Specifications

Phase 9 questions are annotated with Item Response Theory (IRT) parameters to feed Phase 5 Adaptive Question Selection.

### IRT Parameters
- **Difficulty ($b$)**: Calibrated scale from $-3.0$ (Very Easy) to $+3.0$ (Extremely Advanced).
- **Discrimination ($a$)**: Measures how effectively the question separates high-ability from low-ability students ($0.5 \le a \le 2.5$).
- **Guessing Pseudo-chance ($c$)**: $0.25$ for 4-option MCQs, $0.0$ for NAT/MSQs.

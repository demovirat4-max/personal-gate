# Phase 9: Official PYQ Classification (1991–2027)

## Taxonomy & Categorization

The GATE CS/IT Past Year Question (PYQ) repository categorizes questions spanning 37 years (1991 to 2027) across multiple criteria:

### Classification Dimensions
1. **Temporal Horizon**:
   - Legacy Era: 1991–2002 (Subjective/Fill-in & 2-mark MCQs)
   - Single Paper Era: 2003–2013 (Standardized 100-mark paper)
   - Multi-Session Era: 2014–2020 (Multiple sessions, early NAT introduced in 2014)
   - Modern Era: 2021–2027 (MSQ introduced in 2021, revised syllabus structure)
2. **Cognitive Taxonomy (Bloom)**:
   - Remember / Recall
   - Understand / Concept
   - Apply / Calculate
   - Analyze / Multi-step Logic

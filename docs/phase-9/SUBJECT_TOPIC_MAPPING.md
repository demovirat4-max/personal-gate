# Phase 9: Subject & Topic Syllabus Mapping (GATE CS/IT 2028)

## Standard Syllabus Tree (11 Core Subjects)

Phase 9 maps the full official GATE CS/IT 2028 syllabus into canonical codes and a Directed Acyclic Graph (DAG) for prerequisite dependencies.

### Syllabus Structure

1. **Engineering Mathematics (EM)**: Discrete Math, Linear Algebra, Calculus, Probability.
2. **General Aptitude (GA)**: Verbal Ability, Numerical Ability, Analytical Aptitude, Spatial Aptitude.
3. **Data Structures (DS)**: Arrays, Stacks, Queues, Linked Lists, Trees, Binary Search Trees, Heaps, Graphs.
4. **Algorithms (Algo)**: Asymptotic Analysis, Searching/Sorting, Greedy, Dynamic Programming, Divide & Conquer, Graph Traversal, NP-Completeness.
5. **Theory of Computation (TOC)**: Regular Languages & Finite Automata, Context-Free Languages & Pushdown Automata, Turing Machines, Decidability.
6. **Compiler Design (CD)**: Lexical Analysis, Parsing, Syntax Directed Translation, Intermediate Code Generation, Runtime Environments, Code Optimization.
7. **Operating Systems (OS)**: Process Management, Threads, CPU Scheduling, Synchronization, Deadlocks, Memory Management, Virtual Memory, File Systems, Disk Scheduling.
8. **Database Management Systems (DBMS)**: ER-Model, Relational Model, Relational Algebra, SQL, Normalization, Transactions & Concurrency Control, Indexing (B/B+ Trees).
9. **Computer Networks (CN)**: OSI/TCP-IP Stack, Data Link Layer (MAC, Framing, Error Detection), Network Layer (IPv4/IPv6, Routing Algorithms, Subnetting), Transport Layer (TCP/UDP, Congestion Control), Application Layer protocols.
10. **Computer Organization & Architecture (COA)**: Machine Instructions & Addressing Modes, ALU, Data-path & Control Unit, Instruction Pipelining, Memory Hierarchy (Cache, Main Memory), I/O Interface.
11. **Digital Logic Design (DLD)**: Boolean Algebra, Logic Gates, Combinational Circuits (Multiplexers, Decoders, Adders), Sequential Circuits (Flip-Flops, Counters, Shift Registers), Number Representations.

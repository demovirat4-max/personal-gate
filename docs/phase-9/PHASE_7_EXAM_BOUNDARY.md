# Phase 9: Phase 7 Exam Engine Boundary

## Test Generator Query Engine Interface

Phase 7 uses Phase 9 query endpoints to construct balanced mock exam papers adhering strictly to official GATE CS/IT blueprints.

### Official Paper Composition Rules
- **Total Marks**: 100 Marks (65 Questions).
- **General Aptitude**: 15 Marks (10 Questions).
- **Subject Section**: 85 Marks (55 Questions across EM and CS Core).
- **Mark Distribution**: 30 1-mark questions, 35 2-mark questions.

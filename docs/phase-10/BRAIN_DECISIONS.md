# Brain Decisions Lifecycle & Synthesis Engine

## Overview

A **Brain Decision** is the primary output object generated by the Global AI Brain. It transforms raw telemetry and reason codes into a structured, actionable plan item that can be rendered in the Command Center UI or auto-scheduled into the student's daily planner.

---

## Decision Lifecycle State Machine

```
   +------------------+
   |    GENERATED     |  <-- Brain Synthesizer executes rule matrix
   +------------------+
            |
            v
   +------------------+
   |    PRESENTED     |  <-- Rendered in Command Center Action Feed
   +------------------+
        /        \
       v          v
+------------+  +------------+
|  ACCEPTED  |  |  DISMISSED |  <-- Student confirms or snoozes action
+------------+  +------------+
      |
      v
+------------+
| EXECUTED   |  <-- Associated focus session or quiz completed
+------------+
```

---

## Database Entity Schema (`brain_decisions`)

```sql
CREATE TABLE IF NOT EXISTS public.brain_decisions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    snapshot_id UUID NOT NULL REFERENCES public.brain_context_snapshots(id),
    reason_code VARCHAR(64) NOT NULL,
    priority_score INT NOT NULL CHECK (priority_score BETWEEN 1 AND 100),
    title TEXT NOT NULL,
    description TEXT NOT NULL,
    action_type VARCHAR(64) NOT NULL, -- 'START_FOCUS_SESSION', 'TAKE_QUIZ', 'REVIEW_MISTAKES', etc.
    action_payload JSONB NOT NULL DEFAULT '{}'::jsonb,
    status VARCHAR(32) NOT NULL DEFAULT 'PRESENTED', -- 'GENERATED', 'PRESENTED', 'ACCEPTED', 'DISMISSED', 'EXECUTED'
    dismissed_reason TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

---

## Synthesis Algorithm Steps

1. **Rule Match**: Evaluates active reason codes for the user's latest context snapshot.
2. **Deduplication**: Suppresses recommendations duplicate to active or recently completed tasks.
3. **Payload Construction**: Attaches specific target route (e.g., `/practice?topic=sorting&mode=pyq`) to `action_payload`.
4. **Confidence Score Calculation**: Assigns score based on telemetry density ($0.0 - 1.0$).

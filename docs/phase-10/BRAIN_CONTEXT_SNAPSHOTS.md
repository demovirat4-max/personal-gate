# Brain Context Snapshots Specification

## Concept & Purpose

A **Context Snapshot** is an immutable, point-in-time state representation of a student's entire preparation profile. Every decision generated by the Global AI Brain is tied directly to a specific `snapshot_id`, ensuring complete reproducibility, auditability, and historical comparison.

## Lifecycle & Storage Strategy

1. **Compilation**: Triggered automatically on user login, session completion, or manual refresh.
2. **Caching**: Stored in Redis / In-Memory cache for 15 minutes to reduce database read load during active focus sessions.
3. **Persistence**: Saved to `brain_context_snapshots` table in Supabase PostgreSQL for long-term historical trend modeling.

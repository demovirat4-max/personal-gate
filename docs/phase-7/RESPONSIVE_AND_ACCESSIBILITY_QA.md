# Responsive & Accessibility QA

## UI/UX Verification Checklist

1. **GATE Scientific Calculator**: Responsive overlay modal verified for mobile, tablet, and desktop viewports.
2. **Question Palette Grid**: Responsive 65-button question palette panel with color coding:
   - Green: Answered.
   - Red: Not Answered.
   - Purple: Marked for Review.
   - Grey: Not Visited.
3. **Accessibility**: ARIA labels on option radio buttons/checkboxes, full keyboard navigation support (`Alt+N` Next, `Alt+P` Previous, `Alt+S` Save).

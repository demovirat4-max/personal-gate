# AI Explanation Boundary

## Strict Boundary Rules
1. **Zero Hallucination Scoring**: AI is NEVER used to calculate scores, verify option matches, or evaluate numerical tolerance ranges. All evaluation is performed by `PureScoringEngine`.
2. **Post-Submission AI Tutoring**: Candidates may request AI explanation step-by-step guidance ONLY AFTER attempt submission.
3. **Safety Guardrails**: AI tutor prompt enforces canonical answer key adherence without overriding exam scores.

# Result & Section Analysis

## Performance Diagnostics Engine
Post-test submission triggers detailed analytical reporting:

1. **Overall Performance**:
   - Total Score / Max Score.
   - GATE Qualifying Cutoff comparison (e.g. CS cutoff ~28.5 marks).
   - Speed & Time per question metric (seconds/mark).
2. **Section Breakdown**:
   - General Aptitude (15 marks) vs Subject Core (85 marks).
   - Subject-wise accuracy and mark yield (e.g. Data Structures: 8/10, OS: 4/12).
3. **Question Type Diagnostics**:
   - MCQ accuracy %, MSQ selection success, NAT rounding error rate.
